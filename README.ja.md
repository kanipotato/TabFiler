# TabFiler

[English README](README.md)

> **開発中** — 現在も機能追加・仕様変更が継続中です。

macOS 向けのタブ式ファイラー。Windows の [Tablacus Explorer](https://tablacus.github.io/explorer.html) のような、タブ＋ウィンドウ分割で複数フォルダを行き来できるファイラーを目指している。Finder のタブでは足りない用途向け。

## 主な機能

- タブによる複数ディレクトリの並行表示（`Cmd+T` で追加 / `Cmd+W` で閉じる）
- ウィンドウ分割（`Cmd+D` で右に分割 / `Cmd+Shift+W` でペインを閉じる）。ペインごとに独立したタブを持つ
- 階層ツリー表示（`NSOutlineView`、遅延展開）
- 戻る / 進む / 上の階層へ（`Cmd+[` / `Cmd+]` / `Cmd+↑`、空白部分のダブルクリックでも上へ）
- ダブルクリックでフォルダを開く・ファイル/アプリを起動、右クリックメニュー（開く / Finder で表示）
- 表示中フルパスのクリップボードコピー
- **ドラッグ&ドロップによるファイルの移動・コピー**（下記）

## ドラッグ&ドロップ

ツリー上のファイル/フォルダを別のフォルダへドラッグして移動できる。**Option キーを押しながらドロップするとコピー**になる（Finder と同じ流儀）。ペインをまたいだドロップにも対応しているので、分割した左右のペインで別フォルダを開いておけば、そのまま移し替えられる。

事故を避けるためのガードをいくつか入れている。

- **書き込み不可のフォルダ**へのドロップは受け付けない
- **フォルダを自分自身の中（または自分の配下）へ**ドロップする操作は受け付けない。シンボリックリンク経由でこのチェックを迂回できないよう、比較前に両方のパスを実体パスへ解決している
- 上記をすり抜けた場合の多重防御として、コピー中に階層が異常に深くなったら中断する**深さガード**を持つ
- **既に同じフォルダにあるもの**をドロップしても何も起きない（無駄な操作にしない）
- **50件を超える一括操作**は、実行前に確認ダイアログを出す
- 同名ファイルが既にある場合は、**スキップ / 両方残す / 置き換え / キャンセル** を選ぶダイアログを出す（相手と自分のサイズ・更新日時を並べて表示する）

**取り消し（Undo）には対応していない。** 途中で失敗しても、そこまでに完了した分をロールバックせず、「どこまで成功して、どこで止まったか」を結果ダイアログで報告する方式にしている。

## 技術構成

- SwiftUI + AppKit ハイブリッド。ツリーは `NSOutlineView` を `NSViewRepresentable` で組み込み
- Swift Package Manager の実行ファイルターゲット。`Package.swift` を Xcode で直接開いて実行できる
- 対象: macOS 13 以降
- ファイル操作の判断ロジック（ドロップ可否・衝突検出・自己内包チェック・深さガード）は AppKit に依存しない `TabFilerCore` に置き、`swift test` で単体テストしている。NSAlert 等の UI は呼び出し側（`FileTreeView`）が担当し、衝突時の選択はクロージャで受け取る形にして純粋ロジック側をテスト可能に保っている

## テスト

```sh
swift test
```

```sh
swift build
swift run
```
